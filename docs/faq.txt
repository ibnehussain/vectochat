VectoChat — Frequently Asked Questions

Q: What is VectoChat?
A: VectoChat is a RAG-based chatbot that answers questions by searching your own documents
   for relevant context, then using gpt-5.4 to generate accurate, grounded replies.

Q: How do I start a conversation?
A: Send a POST to /api/chat with JSON body: {"session_id": "user-123", "message": "your question"}
   The session_id groups messages into a conversation thread.

Q: How is conversation history stored?
A: Each turn is saved in Azure Cosmos DB (conversations container) and cached in Redis.
   Up to 20 turns are kept per session by default (configurable via MAX_HISTORY).

Q: What document formats are supported for ingestion?
A: Currently only plain text (.txt) files. Run the ingest script:
   python -m scripts.ingest --folder ./docs --category general

Q: What happens when no relevant documents are found?
A: The chatbot answers from gpt-5.4 general knowledge and notes that no documents matched.

Q: How do I check if the service is healthy?
A: GET /health returns {"status":"ok","redis":"pong","cosmos":"ok"} when everything is running.

Q: How are embeddings generated?
A: text-embedding-3-small via Azure AI Foundry produces 1536-dimensional float vectors.
   Query embeddings are cached in Redis for 24 hours to save API calls.

Q: What is TOP_K?
A: Number of document chunks retrieved per query. Default is 5. Higher = more context but higher cost.

Q: Can I run VectoChat locally?
A: Yes. Copy .env.example to .env, fill in your Azure credentials, then run:
   uvicorn app.main:app --host 0.0.0.0 --port 8000
